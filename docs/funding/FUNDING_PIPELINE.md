# Funding pipeline

Live opportunity tracker for PDI. Amounts, deadlines, and eligibility **must be re-verified** on official portals before applying.

**Critical distinction:** Funding builds the **technology company** or eligible **pilot/research** activities—not the private construction of a developer’s apartment block.

## Three propositions (one platform)

| ID | Audience | Problem | Funding type |
|----|----------|---------|----------------|
| **A — VC** | Developers, investors, consultants | Disconnected feasibility, land research, design tools | Antler, pre-seed angels |
| **B — Urban** | Counties, municipalities | Fragmented land information, weak proposal assessment | Cities Deliver, UNDP urban |
| **C — Climate** | Green finance, sustainable developers | Drainage, heat, green infrastructure ignored in appraisal | GreenTech, climate funds |

Proprietary commercial core can coexist with grant-funded **open pilot components** where programme terms require it—structure IP boundary before applying.

## 6–8 week funding demo scope

**One parcel** (Ruaka/Ruiru or similar) with:

1. Land acquisition and negotiation assessment  
2. Preliminary regulatory assessment  
3. Three `DesignProposal` options (apartment-led, courtyard, mixed-use)  
4. Cost estimates and financial scenarios each  
5. Amenity / green-space narrative  
6. Evidence confidence + recommendation  
7. PDF investment committee report + map + editable IFC/GeoJSON  

Validate with ≥2 developers, 1 architect, 1 QS.
